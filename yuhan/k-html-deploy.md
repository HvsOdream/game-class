| 항목 | 내 값 |
|------|-------|
| GitHub 계정 | [내 아이디] |

## 1. 최초 세팅 (딱 한 번, 약 30분)

| 단계 | 하는 일 | 확인 |
|------|---------|------|
| ① 가입 | github.com 무료 가입 | 로그인됨 |
| ② 저장소 | 우상단 `+` → New repository → 이름 입력 → **Public** 선택 → Create | 저장소 화면이 열림 |
| ③ 게시 켜기 | 저장소 **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `/(root)` → Save | "Your site is live" 문구 |
| ④ 첫 확인 | 5~10분 뒤 `https://[내아이디].github.io/[저장소]/` 접속 | 페이지가 뜸 |

**체크:** □ Public으로 만들었나 (Private은 Pages가 안 열립니다) □ Branch를 main으로 지정했나 □ 5분 이상 기다렸나

## 2. 폴더·파일 규칙 (이것만 지키면 주소가 예쁘게 나옵니다)

```
[저장소]/
├── [과목폴더]/index.html   ← 주소: .../[저장소]/[과목폴더]/
├── [과목폴더]/자료.pdf     ← 교재에서 다운로드 링크로 연결 가능
└── [다른과목]/index.html
```

**규칙 3가지**
1. 메인 파일 이름은 **반드시 `index.html`** — 그래야 주소 끝에 파일명이 안 붙습니다.
2. 폴더 이름은 **영문 소문자**로 (한글·공백은 주소가 깨집니다). 예: `yuhan`, `game2026`.
3. 같이 배포할 PDF·이미지는 **같은 폴더**에 두고, HTML에서 `<a href="자료.pdf" download>`로 연결합니다.

---

## 3. 배포 실행 (매번, 3분)

### 방법 A — 브라우저 업로드 (권장, 프로그램 설치 불필요)

1. 저장소 → 해당 과목 폴더 열기 → **Add file → Upload files**
2. `index.html`을 끌어다 놓기
3. 커밋 메시지 입력 → **Commit changes**
4. **1~2분 대기** 후 주소 새로고침 (`Ctrl+Shift+R`로 강제 새로고침)

### 방법 B — 명령어 (git을 쓰는 경우)

```bash
cd [내 작업폴더]
git add [과목폴더]/index.html
git commit -m "feat: [무엇을 바꿨는지]"
git push origin main
```

**커밋 메시지 컨벤션:** `feat:` 새 내용 / `fix:` 오류 수정 / `style:` 디자인 / `docs:` 문서

## 4. 업데이트 — 이 스킬의 핵심

**규칙: 고친 파일을 같은 이름(`index.html`)으로 다시 올린다. 끝.**

- 학생에게 준 주소는 **바뀌지 않습니다.** 내용만 최신이 됩니다.
- "수정본_v2_최종.html"을 다시 뿌릴 일이 없어집니다.
- 학생이 옛날 화면을 본다고 하면 → **강제 새로고침(`Ctrl+Shift+R`, 폰은 브라우저 새로고침)** 안내.

| 상황 | 대응 |
|------|------|
| 올렸는데 안 바뀜 | 1~2분 대기 후 강제 새로고침. 그래도면 파일명이 `index.html`인지 확인 |
| 404 페이지 | 폴더명 오타·대소문자 확인, Pages 설정이 main/root인지 확인 |
| 이미지·PDF가 안 열림 | 같은 폴더에 올렸는지, 링크에 한글·공백이 없는지 확인 |
| 폰에서만 깨짐 | HTML에 반응형 설정이 있는지 Claude에게 "휴대폰에서도 잘 보이게 고쳐 줘" 요청 |

## 5. 공유 (배포 다음 단계)

1. **단축 주소** — tinyurl.com 등에서 긴 주소를 짧게 (별칭을 과목명으로 지정하면 외우기 쉽습니다)
2. **QR 코드** — 단축 주소로 QR 생성 → 첫 수업 슬라이드·강의실 게시판에 게시
3. **안내 문구 예시** — "이번 학기 학습자료는 [단축주소]에 있습니다. 즐겨찾기 해두세요. 내용이 갱신되어도 주소는 같습니다."

---

## 6. 배포 전 필수 점검 (공개 주소입니다)

□ 학생 **이름·학번·성적·연락처**가 자료에 없다
□ **출판사 교재 본문·그림**을 그대로 옮기지 않았다 (내가 만든 요약·도식은 가능)
□ **시험 문제·정답**처럼 공개되면 안 되는 자료는 LMS로 보냈다
□ **비밀번호·토큰·개인 연락처**가 파일 안에 없다
□ 배포 후 **내 폰으로 직접 열어** 확인했다
